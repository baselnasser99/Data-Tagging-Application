How It Works

  1. Create Project - Set up your project and its settings
  2. Questions - Free text, or multiple choice when you want comparable answers
  3. Upload Items - Batch upload images and/or audio clips via ZIP file
  4. Hand out tasks - every item × question becomes a task, shared fairly
  5. Assign a group - Work is split evenly; if someone leaves, their unfinished tasks go to the others
  6. Monitor Progress - Track completion and download results

Choosing an answer type

Multiple choice gives answers you can count and compare. The export shows the majority answer and how much people agreed.

Free text suits descriptions. Answers are exported side by side for you to read.
