How the work is split
  • Each task goes to {{ project.answers_per_task }} different {{ "person" if project.answers_per_task == 1 else "people" }}, never the same person twice.

  • Nobody gets more than {{ project.max_questions_per_user }} tasks in this project.
  • If someone leaves the group, their unfinished tasks go to the others. Finished answers are kept.
