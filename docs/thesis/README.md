# Thesis documents: original and updated

This project started as my diploma thesis at the University of Pécs. The thesis was graded on the original code; I later rebuilt the app properly. This folder keeps both versions side by side, so the difference is visible instead of hidden.

| Folder | What it is |
|---|---|
| [`original/`](original/) | The documentation and defence notes as submitted with the thesis, unchanged. Several claims in them were never true of the code (see the comparison). |
| [`updated/`](updated/) | The same three documents rewritten to match the code as it is now and the revised thesis text. |
| [`COMPARISON.md`](COMPARISON.md) | Claim by claim: what the original thesis said, what the original code did, and what is true now. |

The code exactly as graded is kept as the Git tag [`v1.0-thesis-submitted`](https://github.com/baselnasser99/Data-Tagging-Application/tree/v1.0-thesis-submitted).

Section numbers such as "6.5.3" refer to the thesis chapters.
